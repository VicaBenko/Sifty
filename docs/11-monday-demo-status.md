# מצב ההדגמה ליום שני

**תאריך:** 29.08.2026 · **דד-ליין:** יום שני 31.08 · **קהל:** מרצה/מנחה קורס
**תיקיית עבודה:** `%USERPROFILE%\Sift`

---

## למה יש הדגמה בכלל

הדד-ליין התגלה אחרי שנסגר שלב ה-UX. המוצר המלא אינו בר-השגה עד יום שני, ולכן נבנתה **הדגמה נפרדת** תחת `demo/` — קוד לזרוק, כמו `validation/`, שאינו מימוש של אף ספק ואינו משנה את תוכנית הבנייה. הספקים, ה-PRD והחלטות ה-UX נשארו כפי שהם.

---

## מה מוצג

**שני דברים:** חבילת התכנון והדגמה חיה.

ההדגמה היא דף מקומי הנפתח בדפדפן: מקלידים תיאור באנגלית, לוחצים הפעל, ומקבלים תמונות מתאימות — כל אחת עם נימוק ההתאמה, הערוץ שדרכו נמצאה, ורמת ביטחון.

**מאגר התמונות:** 128 תמונות ציבוריות מ-COCO 2017 (`demo/photos/`). **התמונות האישיות אינן מוצגות** — החלטה מודעת שגם מחזקת את הטיעון: מאגר ציבורי סטנדרטי, אי אפשר לטעון שנבחרו דוגמאות נוחות.

**הקטלוג נבנה בערכת האימות עצמה** — `step1_sample.py` ו-`step2_tag.py` ללא שינוי. 128 תמונות, 518 אובייקטים שונים, חציון 9 לתמונה.

---

## שלב 1 — הושלם

כל שבעת קריטריוני הקבלה (D-1 עד D-7) עוברים, כולל `netstat` שמאשר האזנה ל-127.0.0.1 בלבד.

| שאילתה | תוצאות |
|---|---|
| `a dog` | 11 — 10 ודאיות, 1 גבולית |
| `a clock` | 10 |
| `a cat` | 4 |
| `a cup on a table` | 6 |
| `a bowl of food on a table` | 3 |

**המטמון:** הפרדיקטים של חמש השאילתות שמורים ב-`demo/predicates-cache.json`. נבדק עם מפתח API שבור בכוונה — כולן חזרו מהמטמון בלי ניסיון רשת. **ההדגמה עובדת בלי אינטרנט.**

### שני באגים שנמצאו ותוקנו

**1. התאמת תת-מחרוזת.** `cat` נתפסה בתוך `catcher` ו-`location`; `a cat` החזירה 8 תוצאות שרק 4 מהן חתולים. תוקן להתאמת מילה שלמה.

**2. התאמה בתוך צירוף.** `dog` נתפסה בתוך האובייקט `hot dog`. תוקן להתאמת מילת גרעין — התאמה למילה האחרונה בצירוף — כך ש-`coffee cup` עונה ל-`cup` אבל `cat toy` אינו עונה ל-`cat`. בתוספת רשימת חריגים לצירופים מקובעים.

שניהם מכוסים ב-`demo/test_matching.py`. **שניהם החזירו מספרים סבירים לגמרי ונמצאו רק בבדיקה בעין.**

### הרגע החזק בהדגמה — לא תוכנן

תמונת הנקניקיות עדיין חוזרת ל-`a dog`, אך **דרך ערוץ הכיתוב בלבד, ומסומנת גבולית**. הכיתוב באמת אומר "hot dogs" — ראיה אמיתית אך חלשה יותר, וזה בדיוק תפקידו של הערוץ.

לפי החלטת ה-UX, גבולי אינו נבחר כברירת מחדל. **במוצר, "בחר הכל" לא היה מוחק את הצלחת הזאת.**

### דיוק מדוד מול אמת חיצונית

בדיקת `a dog` מול התיוג הידני הרשמי של COCO: **10 מתוך 11 נכונות — 91%.** השגויה היא כפפת בייסבול שהמתייג קרא לה "small dog". אחת מהנכונות היא כלב בגודל **0.16% משטח התמונה** (23×18 פיקסלים).

**לא נגענו בזה.** המוצר בנוי סביב ההנחה שהתיוג אינו מושלם — לכן העתקה להסגר, סקירה, ו-FR-G2. כפפת הבייסבול היא בדיוק התמונה שהמשתמשת הייתה מוציאה מההסגר.

## שלב 2 — הושלם

כל עשר הדרישות (P2-1 עד P2-10) מומשו, וארבעת קריטריוני הקבלה (D-8 עד D-11) עוברים.

**המסלול המלא רץ:** שאילתה → סימון → העתקה להסגר → באנר ממתין-לאישור → שער אישור → מחיקה.

### מה נוסף

| | |
|---|---|
| **תיבות סימון** | ודאי מסומן מראש, גבולי לא. "בחר הכל" ו"נקה בחירה" בשורת הכותרת |
| **סרגל פעולה** | ספירה וגודל חיים בתחתית המסך, וכפתור "העתקת N להסגר" |
| **הסגר** | `demo/quarantine/` — **העתקה בלבד.** המקור נשאר במקומו עד האישור |
| **מניפסט** | `demo/quarantine/manifest.json` — לכל עותק: מקור, גודל, חתימת sha256, השאילתה שהובילה אליו, וחותמת זמן |
| **בדיקת נתיב** | השרת מסרב לעלות אם תיקיית ההסגר נמצאת בתוך תיקיית התמונות |
| **באנר** | "N תמונות ממתינות לאישור" — נקרא מהדיסק בכל טעינה, ולכן שורד הפעלה מחדש של השרת |
| **שער אישור** | ספירה סופית, נתיב תיקיית ההסגר, ואמירה מפורשת שהמקור הוא תיקייה מקומית ולכן המחיקה מקומית בלבד |
| **מחיקה** | רק מקורות שהעותק שלהם עדיין בהסגר. מחיקה במקום, לעולם לא העברה |
| **יומן פעולות** | `demo/operation-log.json` — מזהה, נתיב מקור, תאריך והשאילתה לכל מחיקה, ומדד שחרור לכל סבב |
| **איפוס** | `python demo/reset.py` משחזר מ-`demo/photos_master/`, מרוקן את ההסגר ומוחק את היומן |

### אימות אוטומטי

```
python demo/verify_phase2.py
```

מריץ סבב מלא ללא דפדפן, כולל תרחיש AC-3, ומאפס בסוף. **אין צורך במפתח API** — הפרדיקטים חוזרים מהמטמון. הרצה אחרונה: כל הבדיקות עברו.

מה נמדד בסבב הבדיקה על `a dog`: 11 תוצאות, 10 ודאיות נבחרו מראש, הועתקו להסגר, שתיים הוצאו מהתיקייה ביד, האישור מחק שמונה — והשתיים נשארו. מדד שחרור: 20%. הרצה חוזרת של אותה שאילתה החזירה 3 תוצאות בלבד, כי המחוקות כבר אינן בתיקייה.

### הרגע שכדאי לתרגל

להוציא שתי תמונות מ-`demo\quarantine` בסייר, מול הקהל, ואז לאשר — ולהראות שהשתיים עדיין ב-`demo\photos`. זה AC-3 מוכח בעשר שניות.

**לפני שמתחילים מול קהל:** להריץ `python demo\reset.py`. אחרי כל סבב מחיקה צריך לאפס, אחרת התמונות באמת חסרות.

## הפעלה

**דאבל-קליק על `RUN-DEMO.bat`** בשורש התיקייה — מאפס, מעלה שרת, פותח דפדפן.

או ידנית:

```
cd /d "%USERPROFILE%\Sift"
python demo\reset.py
python demo\serve.py --port 8091
```

בדפדפן: `http://127.0.0.1:8091`

**שתי מלכודות שנתקלנו בהן:**

1. **שינוי בקוד מחייב הפעלה מחדש של השרת.** פייתון טוען את הקובץ פעם אחת.
2. **Windows מאפשר לכמה תהליכים להיתפס על אותו פורט.** הצטברו שלושה תהליכי רפאים והדפדפן קיבל תשובות מהישן. אם משהו מתנהג מוזר — לסגור את כל חלונות הטרמינל ולפתוח אחד נקי.

## מה לומר על "מקצה לקצה"

התהליך מלא — מהגדרת בעיה, דרך שער אימות אמפירי שקבע הכרעה ארכיטקטונית, ועד קוד רץ. הפונקציונליות מודגמת על מאגר ציבורי. **מול תיקייה מסונכרנת אמיתית לא מודגם במכוון** — מסמך 02 מסביר שמחיקה שם מתפשטת לכל המכשירים, וזו בדיוק הסיבה שהמוצר בנוי סביב העתקה ואישור.
